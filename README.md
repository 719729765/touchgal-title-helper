# touchgal-title-helper

**Chrome Manifest V3 浏览器扩展：TouchGal 链接批量标题提取工具**

批量提取网页标题、导出 CSV、批量打开资源页面，以及通过 Kaogal WordPress 后台搜索文章，适用于需要批量整理 Galgame 文章链接的场景。

> ⚠️ 本项目仅作技术学习演示。批量访问第三方网站时，请遵守目标网站的访问规则。使用本工具产生的风险由使用者自行承担。

## 功能特性

1. **批量导入链接**：粘贴多条 URL，每行一条，由后台 Service Worker 执行抓取任务。
2. **单 Tab 复用**：复用临时标签页依次访问链接，减少标签页数量，任务完成后自动关闭临时 Tab。
3. **自动提取标题**：截取网页标题中第一个 `|` 之前的文本作为有效标题。
4. **导出 CSV**：导出标题与原始链接，格式为 `标题,原链接`。
5. **批量打开资源页面**：在原链接后追加 `?tab=resources`，按原始顺序打开。
6. **批量搜索 WordPress 文章**：根据提取的标题打开 Kaogal 后台搜索页面，支持填写分类 ID，并按倒序打开搜索页面。
7. **独立操作界面**：无需点击扩展图标弹窗，所有操作均在扩展的「选项」页面完成。

## 项目结构

```text
touchgal-title-helper/
├── manifest.json    # Chrome 扩展配置
├── options.html     # 操作界面
├── options.js      # 前端交互逻辑
├── background.js   # Service Worker 后台任务
└── README.md       # 项目说明文档
```

## 本地安装

1. 将项目文件下载或克隆到本地同一个文件夹。
2. 使用 Chrome 打开扩展管理页面：

   `chrome://extensions/`

3. 开启页面右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择包含 `manifest.json` 的项目根目录。
6. 在扩展管理页面找到本扩展，打开其「详细信息」，进入「扩展程序选项」页面。

## 使用说明

### 1. 批量提取标题

1. 在操作页面的文本框中粘贴链接列表，每行一个 URL。
2. 点击「启动后台抓取任务」。
3. 等待后台依次访问网页并提取标题。
4. 任务完成后，可导出 CSV 或执行批量打开操作。

### 2. 导出 CSV

点击导出按钮，将提取结果保存为 CSV 文件，包含以下字段：

| 字段 | 说明 |
| --- | --- |
| 标题 | 提取并处理后的网页标题 |
| 原链接 | 对应的原始 URL |

### 3. 批量打开资源页面

点击「批量打开①」，按照原始顺序打开链接，并在链接后追加 `?tab=resources` 参数。

**注意：** 如果原链接已经包含查询参数，直接追加 `?tab=resources` 可能导致 URL 不符合预期。实际使用时应根据目标网站的 URL 规则调整参数拼接逻辑。

### 4. 批量搜索 Kaogal 后台文章

点击「批量打开②」，根据已提取的标题依次打开 WordPress 后台搜索页面。

- **搜索关键词**：提取后的文章标题。
- **分类 ID**：填写数字形式的分类 ID。
- **不限制分类**：分类 ID 留空。
- **打开顺序**：倒序打开搜索页面。

搜索地址格式：

```text
https://www.kaogal.com/wp-admin/edit.php?s=搜索词
```

指定分类时：

```text
https://www.kaogal.com/wp-admin/edit.php?s=搜索词&cat=分类ID
```

搜索词和 URL 参数应进行正确的 URL 编码。实际能否按分类筛选，取决于目标 WordPress 后台的参数处理逻辑。

使用前请先登录具有相应权限的 Kaogal WordPress 后台账号，否则可能跳转到登录页面。

### 5. 清空结果

点击「清空结果」按钮，清空当前提取结果，并清除分类 ID 输入框。

## 注意事项与限制

1. **Service Worker 可能休眠**：Manifest V3 的后台 Service Worker 受浏览器生命周期管理影响，不适合不加控制地一次提交上百条链接，建议每次处理几十条以内。
2. **需要真实标签页**：网页标题通过实际页面访问获取，无法保证完全无标签页地隐形抓取。本项目通过复用单个临时 Tab 减少标签页数量。
3. **登录状态要求**：使用 Kaogal 后台搜索功能前，需要先登录对应的 WordPress 后台。
4. **分类 ID 限制**：分类 ID 应为数字；留空表示不限制分类。
5. **网络与页面加载**：网络延迟、网站访问限制、页面加载速度及目标网站结构变化，都可能影响抓取结果。
6. **URL 参数处理**：批量打开资源页面时，应注意原链接是否已经包含查询参数。

## 延时参数调整

如果网络较慢，或者目标网页加载时间较长，可以在 `background.js` 中查找以下延时设置，并按实际情况调整：

```javascript
await new Promise(resolve => setTimeout(resolve, 2200)); // 页面加载等待，单位：毫秒
await new Promise(resolve => setTimeout(resolve, 1500)); // 每条访问间隔，单位：毫秒
```

调整建议：

- 页面加载等待：适当增加第一处延时。
- 每条访问间隔：适当增加第二处延时，避免访问过于频繁。
- 不建议单纯通过缩短延时来提高速度，过短的等待时间可能导致标题提取失败。

修改完成后，打开 `chrome://extensions/`，点击本扩展的刷新按钮，再重新执行任务。
