touchgal‑title‑helper
Chrome Manifest V3 浏览器扩展，TouchGal 链接批量标题提取工具

⚠️ 本项目仅作技术学习演示，批量访问第三方网站请遵守目标网站访问规则，使用者自行承担使用风险。

----------------------------------------
功能特性
----------------------------------------
1. 批量导入链接列表，后台 Service‑Worker 执行抓取
2. 单Tab复用跳转抓取，不会无限新建大量标签页，抓取完成自动关闭临时Tab
3. 自动截取网页标题第一个 | 竖线之前的文本作为有效标题
4. 导出 CSV 文件：标题,原链接
5. 批量打开①：原链接追加参数 ?tab=resources（正序打开）
6. 批量打开②：Kaogal WordPress后台搜索文章，支持指定分类ID过滤，倒序打开搜索页面
7. 无点击图标弹窗；全部操作在扩展「选项」页面完成

----------------------------------------
本地安装使用
----------------------------------------
1. 将全部项目文件下载到本地同一个文件夹
2. Chrome浏览器打开扩展管理页面：chrome://extensions/
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选中本项目整个文件夹
5. 在浏览器右上角扩展图标上 右键 → 选项，打开操作界面

-------- 操作流程 --------
1. 文本框粘贴链接列表，一行一条URL
2. 点击 启动后台抓取任务，后台自动执行标题提取
3. 抓取完成后，可以：
   - 导出CSV保存标题与原始链接
   - ①原链接追加 ?tab=resources 批量打开
   - ②Kaogal后台按标题搜索批量打开：可填写数字「分类ID」，留空代表不限制分类；倒序打开WP后台搜索列表页
4. 清空结果按钮：清空列表同时清空分类ID输入框

----------------------------------------
重要限制说明
----------------------------------------
1. Manifest V3 Service‑Worker存在浏览器休眠机制，不建议一次性提交上百条链接，推荐单次几十条以内。
2. 抓取网页标题必须使用真实Tab，无法做到完全无Tab隐形爬取；本扩展使用单个Tab复用跳转减少标签页数量。
3. 使用Kaogal WP后台搜索功能，浏览器需要提前登录 kaogal.com 后台账号，否则打开页面会跳转到登录界面。
4. WordPress后台搜索参数：wp‑admin/edit.php?s=搜索词&cat=分类ID，分类ID只接受数字。

----------------------------------------
延时参数调整
----------------------------------------
如果你网络速度较慢，可以修改 background.js 内两处延时：
await new Promise(resolve=>setTimeout(resolve,2200)); // 页面加载等待毫秒
await new Promise(resolve=>setTimeout(resolve,1500)); // 每条访问间隔毫秒

提示：修改完 background.js 后，前往 chrome://extensions/ 点击扩展刷新按钮，修改才会生效。
