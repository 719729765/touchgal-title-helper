# touchgal‑title‑helper
Chrome Manifest V3 浏览器扩展，TouchGal 链接批量标题提取工具

> ⚠️ 本项目仅作技术学习演示，批量访问第三方网站请遵守目标网站访问规则，使用者自行承担使用风险。

## 功能特性
1. ✅ 批量导入链接列表，后台 Service‑Worker 执行抓取
2. ✅ **单Tab复用跳转抓取**，不会无限新建大量标签页，抓取完成自动关闭临时Tab
3. ✅ 自动截取网页标题第一个 `|` 竖线之前的文本作为有效标题
4. ✅ 导出 CSV 文件：`标题,原链接`
5. ✅ 批量打开①：原链接追加参数 `?tab=resources`（正序打开）
6. ✅ 批量打开②：Kaogal WordPress后台搜索文章，**支持指定分类ID过滤**，倒序打开搜索页面
7. ✅ 无点击图标弹窗；全部操作在扩展「选项」页面完成
